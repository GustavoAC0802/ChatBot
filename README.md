# 🎬 CineMaster

## 📖 Sobre o Projeto

O **CineMaster** é um chatbot inteligente desenvolvido para o Telegram, criado para auxiliar usuários na descoberta de filmes e séries através de recomendações personalizadas e conversas em linguagem natural.

Utilizando **Python** como base de desenvolvimento, o projeto integra modelos de inteligência artificial executados localmente com **Ollama** e recursos analíticos do **MindsDB**, permitindo oferecer sugestões relevantes, responder perguntas sobre produções audiovisuais e proporcionar uma experiência conversacional dinâmica diretamente no Telegram.

O projeto explora conceitos de inteligência artificial generativa, processamento de linguagem natural e desenvolvimento de assistentes virtuais voltados para entretenimento.

## ✨ Funcionalidades

- 🤖 Assistente virtual integrado ao Telegram
- 🎬 Recomendações de filmes com base nas preferências do usuário
- 📺 Sugestões de séries por gênero e temática
- 🔍 Consulta de informações sobre produções audiovisuais
- 💬 Conversação em linguagem natural
- 🧠 Respostas geradas por inteligência artificial
- ⭐ Recomendações personalizadas
- ⚡ Atendimento instantâneo diretamente pelo Telegram

## 🛠️ Tecnologias Utilizadas

### Inteligência Artificial
- 🦙 Ollama
- 🧠 MindsDB

### Backend
- 🐍 Python

### Plataforma
- 📱 Telegram Bot API

## 🎯 Objetivo

O objetivo do CineMaster é facilitar a descoberta de novos filmes e séries através de uma experiência conversacional intuitiva, utilizando inteligência artificial para compreender preferências, sugerir conteúdos relevantes e tornar a busca por entretenimento mais prática e personalizada.
